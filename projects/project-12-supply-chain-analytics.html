Supply Chain Analytics Platform

Built an end-to-end supply chain analytics platform for a global FMCG company, integrating data from 200+ suppliers, 50 manufacturing plants, and 10,000 distribution points. The platform provides real-time visibility, demand forecasting, and inventory optimization across the entire supply chain network.

01 Business Challenge

  • No unified view across procurement, manufacturing, and distribution
  • Demand forecasting accuracy at 62%, causing $80M in excess inventory
  • Supplier performance data scattered across 15+ disconnected systems
  • Order-to-delivery tracking taking manual effort and days to compile
  • No early warning system for supply chain disruptions
  • Sustainability metrics required by investors but impossible to calculate

03 Technical Implementation

dbt Supply Chain Models

// dbt - Inventory Optimization Model 
-- models/marts/supply_chain/fct_inventory_position.sql
{{
    config(
        materialized='incremental',
        unique_key='inventory_key',
        cluster_by=['location_id', 'snapshot_date']
    )
}}

WITH inventory_on_hand AS (
    SELECT * FROM {{ ref('int_inventory_on_hand') }}
),
in_transit AS (
    SELECT * FROM {{ ref('int_inventory_in_transit') }}
),
demand_forecast AS (
    SELECT * FROM {{ ref('int_demand_forecast') }}
),
safety_stock AS (
    SELECT * FROM {{ ref('int_safety_stock_calc') }}
)

SELECT
    {{ dbt_utils.generate_surrogate_key(['i.location_id', 'i.sku', 'i.snapshot_date']) }} as inventory_key,
    i.location_id,
    i.sku,
    i.snapshot_date,
    i.quantity_on_hand,
    COALESCE(t.quantity_in_transit, 0) as quantity_in_transit,
    i.quantity_on_hand + COALESCE(t.quantity_in_transit, 0) as total_available,
    d.forecast_demand_7d,
    d.forecast_demand_30d,
    s.safety_stock_qty,
    -- Days of Supply calculation
    CASE
        WHEN d.avg_daily_demand > 0
        THEN (i.quantity_on_hand + COALESCE(t.quantity_in_transit, 0)) / d.avg_daily_demand
        ELSE NULL
    END as days_of_supply,
    -- Stock Status
    CASE
        WHEN i.quantity_on_hand < s.safety_stock_qty THEN 'CRITICAL'
        WHEN i.quantity_on_hand < s.reorder_point THEN 'LOW'
        WHEN i.quantity_on_hand > s.max_stock_level THEN 'EXCESS'
        ELSE 'OPTIMAL'
    END as stock_status
FROM inventory_on_hand i
LEFT JOIN in_transit t ON i.location_id = t.destination_id AND i.sku = t.sku
LEFT JOIN demand_forecast d ON i.location_id = d.location_id AND i.sku = d.sku
LEFT JOIN safety_stock s ON i.location_id = s.location_id AND i.sku = s.sku
{% if is_incremental() %}
WHERE i.snapshot_date > (SELECT MAX(snapshot_date) FROM {{ this }})
{% endif %}

06 Key Learnings

  • Data quality from EDI sources requires extensive validation rules
  • Prophet with external regressors significantly improves demand forecasting
  • Real-time tracking requires careful latency SLO definition
  • Business stakeholder involvement in metric definition is critical
  • Snowflake's zero-copy cloning enables safe development environments

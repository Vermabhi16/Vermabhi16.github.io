Real-Time IoT Analytics Platform

Architected and delivered an end-to-end IoT analytics platform processing 500 million events daily from 10,000+ industrial sensors across 25 manufacturing facilities, enabling predictive maintenance, quality monitoring, and operational optimization in real-time.

01 Business Challenge

The manufacturing client operated 25 facilities globally with critical industrial equipment requiring continuous monitoring. The existing system had significant limitations:

  • Reactive maintenance approach leading to $50M+ annual unplanned downtime costs
  • No visibility into equipment health until failure occurred
  • Data from sensors collected in batch mode with 24-hour delays
  • Quality defects detected only at end-of-line inspection
  • Siloed data across facilities with no centralized analytics
  • No capability for predictive maintenance or anomaly detection

02 Solution Architecture

Designed a cloud-native IoT platform leveraging Azure IoT Hub for device connectivity, Azure Stream Analytics for real-time processing, and Databricks for advanced analytics and machine learning model deployment.

Key Architectural Decisions

  • Lambda architecture with hot, warm, and cold paths for different latency requirements
  • Azure IoT Edge for edge computing and local processing during connectivity issues
  • Cosmos DB with time-series optimized partition strategy for equipment state
  • Azure Digital Twins for digital representation of physical manufacturing environment
  • MLflow on Databricks for model versioning and deployment lifecycle management

03 Technical Implementation

Stream Analytics Processing

// Azure Stream Analytics - Anomaly Detection Query 
WITH AnomalyDetection AS (
    SELECT
        IoTHub.ConnectionDeviceId AS DeviceId,
        System.Timestamp() AS EventTime,
        temperature,
        vibration,
        pressure,
        AnomalyDetection_SpikeAndDip(temperature, 95, 120, 'spikesanddips')
            OVER(LIMIT DURATION(second, 120)) AS TempAnomaly,
        AnomalyDetection_SpikeAndDip(vibration, 90, 60, 'spikesanddips')
            OVER(LIMIT DURATION(second, 60)) AS VibrationAnomaly
    FROM IoTHubInput TIMESTAMP BY EventEnqueuedUtcTime
)
SELECT
    DeviceId,
    EventTime,
    temperature,
    vibration,
    CAST(TempAnomaly.Score AS float) AS TempAnomalyScore,
    CAST(VibrationAnomaly.Score AS float) AS VibrationAnomalyScore
INTO AlertOutput
FROM AnomalyDetection
WHERE TempAnomaly.IsAnomaly = 1 OR VibrationAnomaly.IsAnomaly = 1

Databricks Streaming Pipeline

// PySpark - Structured Streaming with Delta Lake 
from pyspark.sql.functions import *
from pyspark.sql.types import *

# Read from Event Hubs
iot_stream = (spark.readStream
    .format("eventhubs")
    .options(**eventhub_conf)
    .load()
    .select(
        get_json_object(col("body").cast("string"), "$.deviceId").alias("device_id"),
        get_json_object(col("body").cast("string"), "$.temperature").cast("double").alias("temperature"),
        get_json_object(col("body").cast("string"), "$.vibration").cast("double").alias("vibration"),
        col("enqueuedTime").alias("event_time")
    ))

# Enrich with device metadata
device_metadata = spark.table("silver.device_registry")

enriched_stream = (iot_stream
    .withWatermark("event_time", "10 minutes")
    .join(device_metadata, "device_id")
    .groupBy(
        window("event_time", "5 minutes", "1 minute"),
        "device_id",
        "facility_id",
        "equipment_type"
    )
    .agg(
        avg("temperature").alias("avg_temp"),
        max("temperature").alias("max_temp"),
        avg("vibration").alias("avg_vibration"),
        stddev("vibration").alias("vibration_stddev")
    ))

# Write to Delta Lake
(enriched_stream.writeStream
    .format("delta")
    .outputMode("append")
    .option("checkpointLocation", "/checkpoints/iot_aggregates")
    .trigger(processingTime="30 seconds")
    .toTable("gold.equipment_telemetry_5min"))

Predictive Maintenance Model

// MLflow - Model Training and Registration 
import mlflow
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

with mlflow.start_run(run_name="predictive_maintenance_v2"):
    # Feature engineering from telemetry data
    features = spark.sql("""
        SELECT
            device_id,
            avg_temp_7d, max_temp_7d, temp_trend,
            avg_vibration_7d, vibration_variance,
            operating_hours, days_since_maintenance,
            failure_label
        FROM gold.equipment_features
    """).toPandas()

    X_train, X_test, y_train, y_test = train_test_split(
        features.drop(['device_id', 'failure_label'], axis=1),
        features['failure_label'], test_size=0.2
    )

    model = RandomForestClassifier(n_estimators=100, max_depth=10)
    model.fit(X_train, y_train)

    mlflow.log_metric("accuracy", model.score(X_test, y_test))
    mlflow.sklearn.log_model(model, "predictive_maintenance_model")
    mlflow.register_model(
        f"runs:/{mlflow.active_run().info.run_id}/predictive_maintenance_model",
        "PredictiveMaintenanceModel"
    )

06 Key Learnings

  • Edge computing is essential for industrial IoT - network latency and reliability are critical
  • Schema evolution in streaming systems requires careful planning with Event Hubs schema registry
  • Cosmos DB partition key design is crucial for time-series query performance
  • ML model monitoring in production requires dedicated infrastructure for drift detection
  • Close collaboration with OT (Operational Technology) teams is essential for sensor integration

Microsoft Fabric Unified Analytics

Led the migration from Azure Synapse Analytics to Microsoft Fabric for a major financial services firm, creating a unified analytics platform that consolidates data engineering, data science, and business intelligence workloads under a single SaaS experience with OneLake as the foundation.

01 Business Challenge

The financial institution operated a complex analytics ecosystem that had grown organically over years, creating significant operational overhead and fragmented user experiences:

  • Multiple disconnected analytics tools (Synapse, ADF, ADLS, Power BI) with separate management
  • Data duplication across services leading to consistency issues and storage costs
  • Complex networking and security configurations across multiple Azure services
  • Siloed teams with different tools unable to collaborate effectively
  • High operational overhead managing multiple service SKUs and capacity
  • Regulatory compliance requiring unified audit trails across all data operations

02 Solution Architecture

Designed a unified Microsoft Fabric implementation leveraging OneLake for centralized storage, Fabric workspaces for environment management, and the full spectrum of Fabric experiences for different persona needs.

03 Technical Implementation

Lakehouse Delta Tables

// PySpark Notebook - Medallion Architecture Processing 
# Bronze to Silver transformation with data quality
from pyspark.sql.functions import *
from delta.tables import DeltaTable

# Read from Bronze lakehouse
bronze_df = spark.read.format("delta").load(
    "abfss://bronze@onelake.dfs.fabric.microsoft.com/transactions"
)

# Data quality checks and cleansing
silver_df = (bronze_df
    .filter(col("transaction_id").isNotNull())
    .filter(col("amount") > 0)
    .withColumn("transaction_date", to_date("transaction_timestamp"))
    .withColumn("amount_usd",
        when(col("currency") == "USD", col("amount"))
        .otherwise(col("amount") * col("exchange_rate"))
    )
    .dropDuplicates(["transaction_id"])
    .withColumn("processing_time", current_timestamp())
)

# Merge into Silver lakehouse
silver_table = DeltaTable.forPath(spark,
    "abfss://silver@onelake.dfs.fabric.microsoft.com/transactions"
)

silver_table.alias("target").merge(
    silver_df.alias("source"),
    "target.transaction_id = source.transaction_id"
).whenMatchedUpdateAll() \
 .whenNotMatchedInsertAll() \
 .execute()

# Optimize for query performance
spark.sql("""
    OPTIMIZE silver.transactions
    ZORDER BY (transaction_date, account_id)
""")

Fabric Data Warehouse - T-SQL

// T-SQL - Dimensional Model in Warehouse 
-- Create fact table with cross-database reference to Lakehouse
CREATE TABLE gold.fct_daily_transactions
AS
SELECT
    t.transaction_date,
    t.account_id,
    a.customer_id,
    a.account_type,
    c.customer_segment,
    c.region,
    COUNT(*) as transaction_count,
    SUM(t.amount_usd) as total_amount,
    AVG(t.amount_usd) as avg_amount,
    SUM(CASE WHEN t.transaction_type = 'CREDIT' THEN t.amount_usd ELSE 0 END) as credit_amount,
    SUM(CASE WHEN t.transaction_type = 'DEBIT' THEN t.amount_usd ELSE 0 END) as debit_amount
FROM silver_lakehouse.dbo.transactions t
INNER JOIN gold.dim_accounts a ON t.account_id = a.account_id
INNER JOIN gold.dim_customers c ON a.customer_id = c.customer_id
WHERE t.transaction_date >= DATEADD(day, -1, GETDATE())
GROUP BY
    t.transaction_date,
    t.account_id,
    a.customer_id,
    a.account_type,
    c.customer_segment,
    c.region;

-- Create statistics for query optimization
CREATE STATISTICS stat_transaction_date ON gold.fct_daily_transactions(transaction_date);
CREATE STATISTICS stat_customer_segment ON gold.fct_daily_transactions(customer_segment);

Direct Lake Semantic Model

// DAX Measures for Power BI 
// YTD Revenue with time intelligence
YTD Revenue =
CALCULATE(
    SUM(fct_daily_transactions[total_amount]),
    DATESYTD(dim_date[date])
)

// Month-over-Month Growth
MoM Growth % =
VAR CurrentMonth = [Total Revenue]
VAR PreviousMonth =
    CALCULATE(
        [Total Revenue],
        DATEADD(dim_date[date], -1, MONTH)
    )
RETURN
    DIVIDE(CurrentMonth - PreviousMonth, PreviousMonth, 0)

// Rolling 30-Day Average
Rolling 30D Avg =
AVERAGEX(
    DATESINPERIOD(dim_date[date], MAX(dim_date[date]), -30, DAY),
    [Daily Revenue]
)

Modern Cloud Data Warehouse

Led the migration from legacy on-premises data warehouse to a modern cloud-native analytics platform using Snowflake, dbt, and Apache Airflow. Implemented dimensional modeling best practices and analytics engineering workflows to support 500+ analysts and data scientists.

01 Business Challenge

The healthcare organization was running a 15-year-old on-premises data warehouse that could no longer meet growing analytics demands. Critical challenges included:

  • Legacy Teradata system with escalating licensing costs exceeding $3M annually
  • ETL pipelines taking 12+ hours leaving no time for reruns or error recovery
  • No ability to scale compute for peak reporting periods (month-end, year-end)
  • Data transformation logic embedded in stored procedures with no version control
  • Limited documentation and tribal knowledge making changes risky
  • Growing demand for self-service analytics and data science capabilities

02 Solution Architecture

Designed a modern analytics stack with Snowflake as the cloud data warehouse, dbt for transformation layer implementing analytics engineering best practices, and Apache Airflow for orchestration. The architecture follows ELT patterns with clear separation of concerns.

03 Technical Implementation

dbt Dimensional Model

// dim_patients.sql - SCD Type 2 Patient Dimension 
{{
    config(
        materialized='incremental',
        unique_key='patient_sk',
        on_schema_change='sync_all_columns'
    )
}}

with source as (
    select * from {{ ref('stg_epic__patients') }}
),

transformed as (
    select
        {{ dbt_utils.generate_surrogate_key(['patient_id', 'effective_date']) }} as patient_sk,
        patient_id,
        medical_record_number,
        first_name,
        last_name,
        date_of_birth,
        gender,
        race,
        ethnicity,
        primary_language,
        marital_status,
        -- Address handling with PII masking
        {{ mask_pii('address_line_1') }} as address_line_1,
        city,
        state,
        {{ mask_zip('zip_code') }} as zip_code,
        -- Insurance info
        primary_insurance_id,
        primary_insurance_name,
        -- SCD Type 2 fields
        effective_date,
        {{ dbt_utils.current_timestamp() }} as loaded_at,
        case when lead(effective_date) over (
            partition by patient_id order by effective_date
        ) is null then true else false end as is_current
    from source
)

select * from transformed
{% if is_incremental() %}
    where loaded_at > (select max(loaded_at) from {{ this }})
{% endif %}

dbt Data Quality Tests

// _core__models.yml - Schema Tests 
version: 2

models:
  - name: fct_encounters
    description: "Healthcare encounter fact table at the grain of one row per patient encounter"
    columns:
      - name: encounter_sk
        description: "Surrogate key for the encounter"
        tests:
          - unique
          - not_null

      - name: patient_sk
        description: "Foreign key to dim_patients"
        tests:
          - not_null
          - relationships:
              to: ref('dim_patients')
              field: patient_sk

      - name: encounter_date
        description: "Date of the encounter"
        tests:
          - not_null
          - dbt_utils.accepted_range:
              min_value: "'2010-01-01'"
              max_value: "current_date()"

      - name: total_charges
        description: "Total charges for the encounter"
        tests:
          - dbt_utils.accepted_range:
              min_value: 0
              max_value: 10000000

Airflow Orchestration

// dbt_daily_dag.py - Airflow DAG 
from airflow import DAG
from airflow.operators.bash import BashOperator
from airflow.providers.slack.operators.slack_webhook import SlackWebhookOperator
from datetime import datetime, timedelta

default_args = {
    'owner': 'data-engineering',
    'depends_on_past': False,
    'retries': 2,
    'retry_delay': timedelta(minutes=5),
}

with DAG(
    'dbt_daily_transformation',
    default_args=default_args,
    schedule_interval='0 6 * * *',
    start_date=datetime(2024, 1, 1),
    catchup=False,
    tags=['dbt', 'analytics']
) as dag:

    dbt_deps = BashOperator(
        task_id='dbt_deps',
        bash_command='cd /opt/airflow/dbt && dbt deps'
    )

    dbt_run_staging = BashOperator(
        task_id='dbt_run_staging',
        bash_command='cd /opt/airflow/dbt && dbt run --select staging'
    )

    dbt_run_marts = BashOperator(
        task_id='dbt_run_marts',
        bash_command='cd /opt/airflow/dbt && dbt run --select marts'
    )

    dbt_test = BashOperator(
        task_id='dbt_test',
        bash_command='cd /opt/airflow/dbt && dbt test'
    )

    notify_success = SlackWebhookOperator(
        task_id='notify_success',
        message='dbt daily run completed successfully',
        trigger_rule='all_success'
    )

    dbt_deps >> dbt_run_staging >> dbt_run_marts >> dbt_test >> notify_success

SAP Azure ETL Manufacturing

SAP Enterprise Data Integration

Led a large-scale SAP BW and S/4HANA data integration project for a global manufacturing company, extracting 500+ tables and 10 years of historical data to Azure. The platform enables advanced analytics beyond SAP capabilities while maintaining real-time synchronization with source systems.

01 Business Challenge

  • SAP BW reports taking 4+ hours to run, blocking business decision-making
  • No ability to join SAP data with non-SAP sources for comprehensive analytics
  • SAP licensing costs increasing due to analytics workload on production
  • Historical data retention limited by SAP storage costs
  • Machine learning initiatives blocked by inability to access SAP data
  • S/4HANA migration requiring parallel operation of analytics during transition

SAP Hierarchy Flattening

// PySpark - Cost Center Hierarchy Flattening 
def flatten_sap_hierarchy(hierarchy_df, node_col, parent_col, max_levels=10):
    """Flatten SAP hierarchy structure to dimensional format"""

    from pyspark.sql.functions import coalesce, lit

    # Start with leaf nodes
    result = hierarchy_df.select(
        col(node_col).alias("node_id"),
        col(parent_col).alias("parent_id"),
        col("node_name").alias("level_0_name"),
        col(node_col).alias("level_0_id")
    )

    # Iteratively join to get parent levels
    for level in range(1, max_levels + 1):
        parent_alias = f"p{level}"
        result = result.join(
            hierarchy_df.alias(parent_alias),
            result["parent_id"] == col(f"{parent_alias}.{node_col}"),
            "left"
        ).select(
            result["*"],
            coalesce(col(f"{parent_alias}.{parent_col}"), lit(None)).alias("parent_id"),
            col(f"{parent_alias}.node_name").alias(f"level_{level}_name"),
            col(f"{parent_alias}.{node_col}").alias(f"level_{level}_id")
        )

    return result.drop("parent_id")

06 Key Learnings

  • SAP ODP is the preferred extraction method - avoid direct table access
  • SLT provides best real-time performance but requires careful sizing
  • SAP hierarchies must be flattened for dimensional modeling
  • Currency and unit conversions are critical for accurate analytics
  • SAP Basis team involvement is essential for extraction optimization

AWS Enterprise Data Platform

Architected and implemented a comprehensive AWS data platform for a major retail chain, processing 2 billion transactions daily across 5,000 stores. The platform powers real-time inventory management, customer analytics, and demand forecasting using serverless and managed AWS services.

01 Business Challenge

The retail organization needed to modernize their data infrastructure to support omnichannel retail operations and compete with digital-native competitors:

  • Legacy batch processing with 24-hour delay preventing real-time inventory visibility
  • Siloed data across POS, e-commerce, supply chain, and customer systems
  • No unified customer view across online and offline channels
  • Manual demand forecasting leading to $100M+ in overstock and stockouts annually
  • High infrastructure costs with underutilized on-premises data centers
  • Inability to scale for peak shopping periods (Black Friday, holidays)

02 Solution Architecture

Designed a serverless-first architecture leveraging AWS managed services for scalability and cost optimization. The platform implements a modern data lakehouse pattern with S3 as the foundation and Redshift Serverless for analytics workloads.

03 Technical Implementation

Kinesis Stream Processing

// Lambda Function - Real-time Transaction Processing 
import json
import boto3
from datetime import datetime

def lambda_handler(event, context):
    kinesis = boto3.client('kinesis')
    dynamodb = boto3.resource('dynamodb')
    inventory_table = dynamodb.Table('real-time-inventory')

    for record in event['Records']:
        payload = json.loads(record['kinesis']['data'])

        # Update real-time inventory
        response = inventory_table.update_item(
            Key={
                'store_id': payload['store_id'],
                'sku': payload['sku']
            },
            UpdateExpression='''
                SET quantity = quantity - :qty,
                    last_sale_time = :time,
                    daily_sales = daily_sales + :qty
            ''',
            ExpressionAttributeValues={
                ':qty': payload['quantity'],
                ':time': datetime.utcnow().isoformat()
            },
            ReturnValues='UPDATED_NEW'
        )

        # Check reorder threshold
        new_qty = response['Attributes']['quantity']
        if new_qty < payload.get('reorder_point', 10):
            trigger_reorder_alert(payload['store_id'], payload['sku'])

    return {'statusCode': 200, 'processed': len(event['Records'])}

Glue ETL Job

// PySpark Glue Job - Transaction Aggregation 
from awsglue.context import GlueContext
from awsglue.transforms import *
from pyspark.sql.functions import *
from pyspark.sql.window import Window

glueContext = GlueContext(SparkContext.getOrCreate())
spark = glueContext.spark_session

# Read from Iceberg table
transactions = spark.read.format("iceberg").load(
    "glue_catalog.retail.raw_transactions"
)

# Aggregate daily sales by store and product
daily_sales = (transactions
    .filter(col("transaction_date") == current_date())
    .groupBy("store_id", "product_id", "category")
    .agg(
        sum("quantity").alias("units_sold"),
        sum("total_amount").alias("revenue"),
        countDistinct("customer_id").alias("unique_customers"),
        avg("unit_price").alias("avg_selling_price")
    )
    .withColumn("revenue_rank",
        dense_rank().over(
            Window.partitionBy("store_id").orderBy(desc("revenue"))
        )
    ))

# Write to Iceberg with merge
daily_sales.writeTo("glue_catalog.retail.daily_sales_summary") \
    .option("merge-schema", "true") \
    .overwritePartitions()
